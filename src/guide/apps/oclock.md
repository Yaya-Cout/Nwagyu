# O'clock



O'clock is a clock inside of the calculator. However, the actual time at the start is required since the Numworks Calculator doesn't run anything when powered off. But you can still use it if a classroom doesn't have a clock like 95% of classrooms. Just don't let it run until the battery runs out. This app is quite imprecise though.



## How to use the app



At the start, enter the current time with 0-9 keys, BACK and EXE. Then let it run to keep track of the time.
