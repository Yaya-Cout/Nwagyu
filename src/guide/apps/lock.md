# Lock

This application allows you to lock your NumWorks calculator with a password.
The only way to bypass the password is to reset the calculator, which will erase all data.

## Download

Official releases are available on [GitHub Releases](https://github.com/SaltyMold/Lock-Numworks/releases).

If you prefer, you can use this direct link:

- [Lock 1.1.1](https://github.com/SaltyMold/Lock-Numworks/releases/download/Lock-Numworks-v1.1.1/Lock.nwa)

## How to use the app

| Keys      | Actions          |
|-----------|------------------|
| OK        | Confirm password |
| Numbers   | Type password    |
| Delete    | Delete character |
